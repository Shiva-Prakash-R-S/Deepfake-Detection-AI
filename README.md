# 🛡 Deepfake Detection AI

A Full Stack AI-powered web application that detects whether an uploaded image is **Real** or **Fake (Deepfake)** using a hybrid deep learning architecture.

---

## 🚀 Features

- Upload Image
- AI-based Deepfake Detection
- EfficientNet-B0 Feature Extraction
- FFT Frequency Analysis
- Attention Fusion
- Confidence Score
- Fake Probability
- Real Probability
- REST API using Flask
- React Frontend

---

## 🧠 Algorithm

CNN + FFT + Attention Fusion
